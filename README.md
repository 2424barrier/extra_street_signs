# Extra Street Signs 

This mod adds EU signs to Luanti using the textures from webdesigner's `streets` mod (https://github.com/minetest-mods/streets), without clashing with existing mods. Crafting recipes not currently available.

**NOTE: Mod will _not_ work with 'streets' by webdesigner, and will convert any old signs on initial boot.**
